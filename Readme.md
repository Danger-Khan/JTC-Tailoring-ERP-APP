# 🧵 جهاګړ ټکستایل او کلودنګ ای آر پی (JTC Tailoring ERP)

پیتھون (Python) پر بنسټ جوړ شوی د خیاطۍ دکانونو (Tailoring Shops) او کاليو جوړولو فابریکو د مدیریت او تعقیب لپاره یو پرمختللی او چټک غوښتنلیک دی، کوم چې د ډیسک ټاپ او ویب دواړو لپاره کارول کیږي.

---

## 📋 د پروژې عمومي کتنه
دا سیسټم د دې لپاره ډیزاین شوی چې د خیاطۍ دکانونو ټولې مهمې چارې په اتوماتیک او منظمه توګه اداره کړي:
* د پیرودونکو د معلوماتو او اندازو (Measurements) ساتنه.
* د فرمایشونو (Orders) تعقیب او د رسیدونو چاپول.
* د کارمندانو او د هغوی د کارونو مدیریت.
* د سټاک او انوینټري (Inventory) څارنه.

---

## 🛠️ تخنیکي اړتیاوې او پکیجونه (Dependencies)

دا پروژه د **Python 3.12 (وینډوز)** سره ازمول شوې ده. د اړینو پکیجونو د نصبولو لپاره لاندې امر وکاروئ:

```bash
python -m pip install -r requirements.txt
